# Satellite Telemetry System — Frontend

Frontend for the **Satellite Telemetry System**, built with **React and Vite**.

## Technologies

* React
* Vite
* JavaScript
* ESLint

## Installation

```bash
npm install
```

## Run the Project

```bash
npm run dev
```

Frontend runs at:

```text
http://localhost:5173
```

## Backend

The frontend communicates with the **Django REST API**:

```text
http://127.0.0.1:8000
```

## Project Structure

```text
frontend/
├── public/
├── src/
├── package.json
└── vite.config.js
```
